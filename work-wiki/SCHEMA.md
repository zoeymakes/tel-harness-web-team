# Work Wiki Schema

## 폴더 기준

| 폴더 | 역할 |
|---|---|
| `00_inbox/` | 아직 정리하지 않은 새 자료 |
| `10_sources/` | 원본 자료 보존 |
| `20_concepts/` | 반복해서 설명하는 개념 |
| `30_entities/` | 사람, 팀, 도구, 시스템 |
| `40_projects/` | 진행 중인 일, 결정사항, 산출물 |
| `50_playbooks/` | 반복 업무 절차 |
| `60_questions/` | 자주 묻는 질문과 답변 후보 |
| `70_briefings/` | Wiki를 읽고 만든 요약/보고서 |

## 운영 원칙

- 원본 자료는 지우지 않습니다.
- 출처, 날짜, 작성 맥락을 남깁니다.
- 비슷한 토픽이 이미 있으면 새 파일보다 기존 페이지 확장을 우선합니다.
- 기존 내용과 충돌하면 삭제하지 말고 `[확인 필요]`로 표시합니다.
- 확실한 사실과 AI의 추정은 구분합니다.
- 외부 공유용 결과물에는 민감하거나 비공개인 자료를 넣지 않습니다.

## 토픽 페이지 템플릿

```md
# [토픽명]

관련: [[관련 문서 A]] · [[관련 문서 B]]
Facets: 검색에 도움이 되는 키워드

## 핵심
지금까지 확인한 결론을 짧게 적습니다.

## 근거
- 원본에서 확인한 내용 [source: 출처, 날짜]

## 적용
실제 업무에서 어떻게 쓰는지 적습니다.

## Open Questions
- 아직 확인이 필요한 질문

## Related
- [[연결 문서]]
```
