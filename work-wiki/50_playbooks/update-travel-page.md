# 숙소 검색 페이지 업데이트 절차

관련: [[숙소 예약 결정 마찰]]
Facets: playbook · web-team · travel page

## 핵심

숙소 검색 페이지를 수정할 때는 리서치, 범위 정의, UX, 카피, 구현, QA 순서로 확인합니다.

## 절차

1. 사용자 요청을 한 문장으로 정리합니다.
2. `references/travel-booking-product-brief.md`를 확인합니다.
3. 검색, 필터, 카드, CTA 중 이번에 바꿀 범위를 정합니다.
4. `starter/` 파일을 수정합니다.
5. `python3 scripts/check_repo.py`를 실행합니다.
6. 남은 확인 질문을 보고합니다.
