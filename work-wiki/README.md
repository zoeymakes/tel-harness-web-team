# Work Wiki

AI와 함께 다시 꺼내 쓸 업무 지식을 정리하는 폴더입니다.

## 기본 흐름

1. 새 자료는 `00_inbox/`에 둡니다.
2. 원본은 `10_sources/`에 보존합니다.
3. 반복해서 쓰는 설명은 `20_concepts/`에 정리합니다.
4. 사람, 팀, 도구, 시스템은 `30_entities/`에 둡니다.
5. 진행 중인 일과 결정사항은 `40_projects/`에 둡니다.
6. 반복 절차는 `50_playbooks/`에 둡니다.
7. 자주 묻는 질문은 `60_questions/`에 둡니다.
8. Wiki를 읽고 만든 요약/보고서는 `70_briefings/`에 둡니다.

## Claude에게 시켜볼 문장

```txt
work-wiki/00_inbox 안의 자료를 읽고 SCHEMA.md 기준으로 정리해줘.
원본은 보존하고, 반복해서 쓸 개념과 절차를 분리해줘.
```
