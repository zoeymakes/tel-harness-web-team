# QA Check

## 확인 순서

1. 사용자가 요청한 기능이 화면에 있는지 확인합니다.
2. `starter/index.html`을 열 수 있는지 확인합니다.
3. CSS/JS 파일 경로가 맞는지 확인합니다.
4. 모바일 너비에서 레이아웃이 무너지지 않는지 확인합니다.
5. 버튼 텍스트가 행동을 설명하는지 확인합니다.
6. 이미지 alt, label, aria-label 등 기본 접근성을 확인합니다.
7. `python3 scripts/check_repo.py`를 실행합니다.

## 결과 형식

```txt
통과:
- 

수정 필요:
- 

확인 필요:
- 
```
