# Copy Review

`references/toss-style-consumer-copy.md`를 기준으로 화면의 모든 문구를 교정하는 절차입니다.

## 절차

1. `starter/index.html`과 `starter/app.js`에서 사용자에게 노출되는 모든 문자열을 수집한다. JS 템플릿 문자열 안의 동적 문구(요약 메시지, CTA 상태 문구)도 포함한다.
2. 아래 탐지 패턴으로 문제 문구를 찾는다.
3. 교정표(위치 / 현재 / 제안 / 이유)를 만든 뒤 반영한다.
4. 교정 후에도 가격·조건·상태 정보가 빠지지 않았는지 확인한다.

## 탐지 패턴

**번역투** — 발견 즉시 교정
| 패턴 | 예 | 교정 방향 |
| --- | --- | --- |
| ~을 경험하세요 / 만나보세요 | "새로운 여행 경험을 만나보세요" | 실제 행동으로: "날짜와 인원을 입력하고 예약 가능한 숙소를 확인하세요" |
| 피동·이중 존대 | "~가 제공됩니다", "~하실 수 있으십니다" | 능동 단문: "~을 확인하세요" |
| 명사 나열 종결 | "완벽한 휴식을 위한 프리미엄 스테이" | 정보 문장: "조용한 객실, 늦은 체크아웃, 조식 포함" |

**과장·빈말** — 금지어: 최고의, 혁신적인, 완벽한, 특별한, 새로운 경험, 프리미엄(근거 없이). grep으로 일괄 검색해 잡는다.

**모호한 버튼** — "확인", "검색", "더보기", "클릭" 단독 사용 금지. 누르면 일어나는 일을 동사로: "예약 가능 숙소 보기", "조건 다시 선택", "날짜 바꾸기".

## 작성 규칙

- 한 문장에 하나의 정보. 두 가지를 말하려면 문장을 나눈다.
- 숫자·조건은 문구에 직접 쓴다: "저렴한 가격" ❌ → "1박 98,000원" ⭕
- 시스템 메시지는 사용자의 입력을 되풀이한다: "제주 · 2명 조건에 맞는 숙소 3개"
- 불확실한 것을 확정처럼 쓰지 않는다. mock demo 고지는 유지한다.
- 같은 행동은 화면 어디서든 같은 문구를 쓴다.

## 교정 예시

- ❌ 새로운 여행 경험을 만나보세요 → ⭕ 날짜와 인원을 입력하고 예약 가능한 숙소를 확인하세요
- ❌ 완벽한 휴식을 위한 프리미엄 스테이 → ⭕ 조용한 객실, 늦은 체크아웃, 조식 포함 숙소
- ❌ 지금 바로 시작하기 → ⭕ 예약 가능 숙소 보기
- ❌ 검색 결과가 없습니다 → ⭕ 이 조건에 맞는 숙소가 없어요. 필터를 바꾸거나 조건을 다시 선택해 보세요
