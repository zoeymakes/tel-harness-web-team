# Copy Review

## 절차

1. 사용자가 이해하기 어려운 추상어를 찾습니다.
2. 버튼과 제목이 실제 행동을 말하는지 확인합니다.
3. 과장된 표현을 정보 중심 문장으로 바꿉니다.
4. 같은 의미가 반복되면 줄입니다.
5. 고객에게 필요한 정보가 빠졌으면 보완합니다.

## 바꾸기 예시

- 나쁨: 새로운 여행 경험을 만나보세요.
- 좋음: 날짜와 인원을 입력하고 예약 가능한 숙소를 확인하세요.

- 나쁨: 완벽한 휴식을 위한 프리미엄 스테이
- 좋음: 조용한 객실, 늦은 체크아웃, 조식 포함 숙소
