# Design System Application

## 절차

1. `references/airbnb-style-design.DESIGN.md`를 읽습니다.
2. 색은 CTA와 상태 표시 위주로 제한합니다.
3. 카드에는 이미지 영역, 핵심 정보, 가격, CTA를 일정하게 배치합니다.
4. 여백은 넉넉하게 두되 정보 흐름을 끊지 않습니다.
5. 장식보다 비교 가능성을 우선합니다.

## 금지

- 의미 없는 그라디언트와 장식 과다 사용
- CTA가 여러 색으로 흩어지는 구성
- 카드마다 정보 순서가 다른 구성
