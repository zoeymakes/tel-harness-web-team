# Design System Application

디자인의 **모든 구체 값(색·radius·spacing·타이포·컴포넌트 스펙)은 `references/design-system.md`가 정합니다.** 브리프에 "디자인 방향" 오버라이드가 있으면 그쪽이 우선합니다. 이 스킬은 값을 정하지 않고, 그 값을 일관되게 적용하는 **규칙**만 정합니다. 레퍼런스 파일을 다른 디자인 시스템으로 교체하면 이 규칙은 그대로 두고 스타일만 바뀌어야 합니다 — 그래서 이 문서에 특정 hex·px 값을 적지 않습니다.

## 절차

1. `references/design-system.md`를 읽고 토큰(색/타이포/radius/spacing)과 컴포넌트 스펙을 파악한다. 브리프 오버라이드가 있으면 해당 값으로 대체한다.
2. 레퍼런스 토큰 중 이번 페이지에 필요한 것을 `site/styles.css`의 `:root` CSS 변수로 옮긴다. 변수명은 역할 기반(`--primary`, `--text`, `--muted`, `--surface` 등)으로 짓고, 값은 레퍼런스에서만 가져온다.
3. 변수 밖 하드코딩 값(hex 색, 임의 radius, 임의 그림자)을 찾아 변수로 치환한다. 예외: `site/assets/` SVG 일러스트 내부의 장면 색 — 이미지는 콘텐츠이므로 장면 팔레트를 자유롭게 쓰되, 브랜드 primary와 경쟁하지 않게 한다.
4. 아래 위계 규칙을 적용한다.
5. 모바일 브레이크포인트에서 토큰이 유지되는지 확인한다.

## 위계 규칙 (값이 아니라 구조)

**색**
- 주 강조색(primary)은 주 CTA와 핵심 상태 강조에만 쓴다. 화면당 주 CTA 스타일은 한 종류, primary가 3곳 이상 흩어지면 위계가 무너진 것.
- 본문은 기본 텍스트색, 보조 정보만 muted 계열. 가격·CTA·상태 같은 **결정 정보에 muted 금지**.
- 배경은 레퍼런스에 정의된 surface 층위만 쓴다. 레퍼런스에 없는 배경색을 즉석에서 만들지 않는다.
- 채운 CTA는 배경과 텍스트 대비 **4.5:1(AA) 이상**이어야 한다. 레퍼런스의 기본 primary가 미달이면 레퍼런스가 함께 정의한 더 어두운 변형(active/dark 등)을 채움 배경으로 쓰고, 기본 primary는 hover·포커스 링·선택 상태로 돌린다.

**radius** — 레퍼런스에 정의된 단계만 쓴다. 컴포넌트별 대응(카드, 입력, 버튼, 칩)은 레퍼런스의 컴포넌트 스펙을 따르고, 레퍼런스에 없는 radius 값을 즉석에서 만들지 않는다.

**여백**
- 레퍼런스의 spacing 스케일 값만 쓴다. 스케일 밖 임의 px를 만들지 않는다.
- 섹션 간 여백, 카드 내부 padding, 그리드 gap은 각각 레퍼런스가 정한 값으로 통일하고 화면 전체에서 같은 리듬을 유지한다.
- 여백을 줄여서 정보를 더 넣기보다, 정보를 줄여서 여백을 지킨다.

**타이포그래피**
- 레퍼런스의 타이포 계층에서 고르되, 한 페이지에서 실제 사용하는 크기 단계는 4~5개 이내로 제한한다(제목/부제목/본문/캡션 역할).
- 가격·평점 같은 숫자는 굵기로 강조하고 색으로만 강조하지 않는다.
- 레퍼런스가 지정한 폰트를 쓸 수 없으면(라이선스 폰트 등) 레퍼런스의 대체 폰트 안내 또는 시스템 폰트 스택을 따르고, 웹폰트 CDN을 추가하지 않는다.

**CTA**
- 주 행동: 채운 primary 계열(위 AA 규칙 적용). 보조 행동: 외곽선·표면색 스타일로 구분하고 주 CTA와 같은 채움을 쓰지 않는다.
- 카드 CTA는 모든 카드에서 같은 위치·크기. 상태(가능/불가)는 문구와 스타일로만 구분하고 위치는 유지한다.
- 터치 타겟은 레퍼런스의 최소 높이 기준(없으면 44px 이상)을 지킨다.

## 금지

- UI 크롬(버튼·카드 표면·배경·네비)에 의미 없는 그라디언트, 그림자 남발, 장식용 애니메이션 (그림자는 레퍼런스가 정의한 단계만. 이미지 에셋 내부는 예외 — 일러스트는 장식이 아니라 콘텐츠)
- 주 CTA 색이 화면 여러 곳에 흩어지는 구성
- 카드마다 정보 순서·여백이 다른 구성
- 레퍼런스에 없는 색·radius·spacing을 즉석에서 추가하는 것 (필요하면 레퍼런스/브리프 수정을 먼저 제안)

## 점검 출력 형식

```txt
토큰 대조:
- (변수명): 일치 | 불일치(현재값 → 교정값)

위계 위반:
- [상|중|하] 규칙 — 위치(파일:줄) — 교정값
```
