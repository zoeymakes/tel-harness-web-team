# Design System Application

`references/airbnb-style-design.DESIGN.md`의 토큰을 `starter/styles.css`에 일관되게 적용하기 위한 절차입니다. 기준은 취향이 아니라 토큰입니다.

## 절차

1. `references/airbnb-style-design.DESIGN.md`의 토큰 표를 읽는다.
2. `starter/styles.css`의 `:root` 변수가 토큰과 1:1 대응하는지 대조한다.
3. 변수 밖 하드코딩 값(hex 색, 임의 radius, 임의 그림자)을 찾아 변수로 치환한다. 예외: 이미지 placeholder 그라디언트.
4. 아래 위계 규칙을 적용한다.
5. 모바일 브레이크포인트에서 토큰이 유지되는지 확인한다.

## 위계 규칙

**색**
- `--primary`(#ff385c)는 주 CTA와 상태 강조 전용. 화면당 주 CTA 스타일은 한 종류.
- 본문 텍스트는 `--text`, 보조 정보만 `--muted`. 가격·CTA·예약 상태 같은 **결정 정보에 `--muted` 금지**.
- 배경 층위: 페이지 `--bg` → 카드/입력 `--surface` → 강조 배경 `--warm`. 세 층위 밖의 배경색을 만들지 않는다.

**radius** — 세 단계만: 카드 24px(`radius.card`), 입력 16px(`radius.input`), 버튼 999px(`radius.button`). 네 번째 값이 필요해 보이면 이 셋 중 하나로 맞춘다.

**여백**
- 좌우 패딩은 `page_x`(24px) 기준, 섹션 간은 `section_y`(56px) 기준. 카드 내부는 20px 패딩 + 8~16px 리듬.
- 여백을 줄여서 정보를 더 넣기보다, 정보를 줄여서 여백을 지킨다.

**타이포그래피**
- 크기 단계 4개 이하: 페이지 제목 / 섹션·카드 제목 / 본문 / 캡션.
- 가격·평점 같은 숫자는 굵기로 강조하고 색으로만 강조하지 않는다.

**CTA**
- 주 행동: `--primary` 채움 + 흰 텍스트. hover는 `--primary-dark`.
- 보조 행동(필터, 날짜 바꾸기): 외곽선 또는 반전 스타일. 주 CTA와 같은 채움 스타일 금지.
- 카드 CTA는 모든 카드에서 같은 위치·크기. 상태(가능/불가)는 문구와 스타일로만 구분.

## 금지

- 의미 없는 그라디언트, 그림자 남발, 장식용 애니메이션
- 주 CTA 색이 화면 여러 곳에 흩어지는 구성
- 카드마다 정보 순서·여백이 다른 구성
- 토큰에 없는 색·radius를 즉석에서 추가하는 것 (필요하면 토큰 문서 수정을 먼저 제안)

## 점검 출력 형식

```txt
토큰 대조:
- (변수명): 일치 | 불일치(현재값 → 교정값)

위계 위반:
- [상|중|하] 규칙 — 위치(파일:줄) — 교정값
```
