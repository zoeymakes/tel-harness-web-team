# Travel Page Builder

## 절차

1. 사용자가 찾는 여행 상황을 한 줄로 정리합니다.
2. 검색 조건을 지역, 날짜, 인원으로 단순화합니다.
3. 숙소 카드는 이름, 위치, 가격, 평점, 특징, 예약 가능 여부를 보여줍니다.
4. 필터는 가격대, 숙소 유형, 편의시설 정도로 제한합니다.
5. CTA는 사용자가 바로 할 수 있는 행동으로 씁니다.
6. 실제 백엔드가 없으면 mock data라는 점을 코드와 화면에서 명확히 둡니다.

## 품질 기준

- 첫 화면에서 검색 목적이 분명해야 합니다.
- 숙소 카드 하나만 봐도 비교 기준이 보여야 합니다.
- 모바일에서 검색 폼과 카드가 세로로 자연스럽게 쌓여야 합니다.
