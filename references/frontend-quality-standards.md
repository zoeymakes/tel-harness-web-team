# Frontend Quality Standards

## Static page 기준

- `starter/index.html`에서 CSS와 JS 경로가 맞아야 합니다.
- JS가 실패해도 기본 안내 문구는 보여야 합니다.
- 폼 요소에는 label이 있어야 합니다.
- 버튼은 클릭 가능한 요소로 구현합니다.
- 카드 데이터는 `starter/app.js`의 배열로 관리합니다.

## Responsive 기준

- 720px 이하에서 검색 폼은 한 줄이 아니라 세로 배치로 바뀝니다.
- 숙소 카드는 한 열로 쌓입니다.
- CTA 버튼은 손가락으로 누르기 쉬운 크기입니다.
