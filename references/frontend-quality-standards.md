# Frontend Quality Standards

## Visual 기준

- 데스크톱 첫 뷰포트(1440×900)에서 콘텐츠 카드의 첫 줄이 보여야 합니다. 검색·필터가 첫 화면 절반을 넘으면 실패입니다.
- 사진 자리는 `site/assets/`의 로컬 이미지로 채웁니다 — 기본은 빌드 시 다운로드한 무료 라이선스 실사진(출처는 `assets/credits.txt`), 네트워크 불가 시 레이어드 SVG 일러스트 폴백. 단색·그라디언트 사각형, 이모지 채움, 런타임 외부 URL 핫링크는 금지입니다.
- 이미지들은 같은 톤·스타일로 통일하되 항목마다 장면을 변주해 서로 구분되게 합니다. 사진·일러스트 혼용 금지.
- 완료 전 헤드리스 브라우저 스크린샷(데스크톱·모바일)을 찍어 직접 확인합니다. 렌더를 보지 않은 "완료"는 없습니다.

## Static page 기준

- `site/index.html`에서 CSS와 JS 경로가 맞아야 합니다.
- JS가 실패해도 기본 안내 문구는 보여야 합니다. (`<noscript>` 포함)
- 폼 요소에는 label이 있어야 합니다.
- 버튼은 클릭 가능한 요소(`<button>`)로 구현하고, 읽을 수 있는 텍스트를 가집니다.
- 반복 렌더링되는 데이터(카드, 목록)는 `site/app.js`의 배열로 관리합니다.

## Responsive 기준

- 720px 이하에서 가로로 나열된 입력 영역은 세로 배치로 바뀝니다.
- 카드·목록은 한 열로 쌓이고, 요소가 겹치지 않습니다.
- CTA 버튼은 손가락으로 누르기 쉬운 크기(최소 높이 44px)입니다.
