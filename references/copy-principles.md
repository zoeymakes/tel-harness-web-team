# Consumer Copy Principles — 기본 문구 기준

소비자용 페이지 문구의 기본 기준입니다. 브리프에 별도 "카피 방향"(예: 격식체, 전문가 대상 톤)이 있으면 그쪽이 우선합니다.

## 원칙

- 사용자의 다음 행동을 먼저 말합니다.
- 짧고 구체적으로 씁니다.
- 어려운 서비스 용어보다 사용자가 쓰는 말을 씁니다.
- 혜택·조건은 숫자와 함께 씁니다. ("저렴한 가격" ❌ → "1박 98,000원" ⭕)
- 불확실한 내용은 확정처럼 말하지 않습니다.

## 버튼 문구 규칙

버튼은 누르면 일어나는 일을 동사로 말합니다. "확인", "검색", "더보기", "클릭" 단독 사용 금지.

예시 (도메인별로 브리프에 맞게 새로 씁니다):

- 숙소 예약: "예약 가능 숙소 보기", "조건 다시 선택", "날짜 바꾸기"
- 커머스: "장바구니에 담기", "재고 있는 상품만 보기"
- 콘텐츠: "이어서 읽기", "전체 목차 보기"

## 피해야 할 문구

- 최고의 / 혁신적인 / 완벽한 / 특별한 / 새로운 경험 / (근거 없는) 프리미엄
- "~을 경험하세요", "~을 만나보세요" 같은 번역투
- 명사 나열로 끝나는 슬로건 ("완벽한 휴식을 위한 프리미엄 스테이")
