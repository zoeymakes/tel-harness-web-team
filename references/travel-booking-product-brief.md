# Travel Booking Product Brief

## 제품 상황

사용자는 여행 날짜와 인원을 정한 뒤, 숙소를 빠르게 비교하고 예약 가능 여부를 확인하고 싶어 합니다.

## 사용자 불안

- 실제로 예약 가능한 숙소인지 모르겠다.
- 최종 가격이 얼마인지 헷갈린다.
- 위치가 여행 목적과 맞는지 판단하기 어렵다.
- 후기와 편의시설을 한눈에 비교하기 어렵다.

## 이번 MVP에 포함할 것

- 지역, 날짜, 인원 검색 영역
- 숙소 카드 리스트
- 가격대/숙소 유형/편의시설 필터
- 예약 가능 여부 CTA
- mock data 기반 카드 렌더링

## 이번 MVP에서 제외할 것

- 실제 결제
- 실제 로그인
- 실제 지도 API
- 실제 Supabase 연결
- 외부 이미지 API
